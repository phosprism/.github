## About

Phos'Prism は、2026年にみょん（Arr.）とくだけん（Staff）を中心に結成した7人組のサークルです。
トランスやハードミュージックを軸に、東方Projectのアレンジ楽曲を制作しています。
前身の Dreamy Records の作品も、公式サイトでアーカイブとして公開しています。
