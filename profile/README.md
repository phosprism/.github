## About

Dreamy Recordsは2022年に結成された東方同人音楽アレンジサークルです。

楽曲制作を中心に、活動しています。

---

## Activities

* 東方Projectアレンジ楽曲制作
* アルバム・EPリリース
* 同人イベント参加 (例大祭、コミケなど)
* Webコンテンツ制作 (ホームページ)
* コミュニティ運営 (Discord)
